# Changelog

All notable changes to FridgePatrol are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-19

### Added

- Responsive cartoon kitchen and interactive SVG refrigerator.
- Click, drag, touch, and keyboard door controls.
- Ten randomized guardian reactions and a tenth-opening secret patrol sequence.
- Synthesized door and character sounds with a persistent sound preference.
- Persistent opening counter, reset control, cold mist, and lighting transitions.
- Reduced-motion support, visible focus states, live announcements, and descriptive SVG content.
- Dependency-free production verifier and GitHub Pages deployment documentation.

### Security

- Added a restrictive document Content Security Policy with no runtime network connections.
- Removed dynamic HTML injection from the opening counter.
